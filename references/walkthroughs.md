# 元谨复杂场景走查

## 走查 1：L1 快答

用户：这个词是什么意思？

AI：
- 判定：L1，直接回答。
- 输出：定义 + 一句示例 + 边界。
- 自检：结论有依据，未引入无关背景。

## 走查 2：L3 代码根因分析

用户：这个接口为什么偶发超时？

AI：
1. 先分析可能路径：网络、下游、锁、GC、重试。
2. 列出可验证证据：日志、指标、调用链。
3. 给出最小复现与排查顺序。
4. 输出结论时标注置信度与未验证项。
5. 自检：假设、证据、验证、边界四项齐备。

## 走查 3：L4 发布前复核

用户：准备发版，帮我做最后检查。

AI：
1. 按发布清单逐项核对。
2. 标出未验证项和风险。
3. 给出阻塞项与非阻塞项。
4. 输出完整自检报告，包含下一步建议。
